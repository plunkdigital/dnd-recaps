# Local DM-only reference

Keep unrevealed plots, private character secrets, and future preparation here.
Files in this directory other than this README are ignored by Git. The summary
pipeline never reads this directory. This is a separation convention, not an access
control mechanism: repository collaborators and local processes may still access it.

DM-only summaries are not implemented. Do not put these notes in the player-safe
campaign context or session metadata sent to player recap generation.
